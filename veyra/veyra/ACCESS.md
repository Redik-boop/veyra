# 🚀 Quick Access to Veyra

If you are the owner or a collaborator of this private repository and want to access the live website, follow the instructions below.

## 🌐 Live Website Link
**URL:** [https://redik-boop.github.io/veyra/](https://redik-boop.github.io/veyra/)

> **Note:** If the repository is private, the GitHub Pages site is still accessible to the public by default unless you have a GitHub Enterprise account with restricted pages.

## 🛠️ How it's Hosted
The website is deployed via **GitHub Actions**. Every time a change is pushed to the `main` branch, the project is automatically:
1. Compiled using Vite.
2. Deployed to GitHub Pages.

## 📲 APK Access
To get the Android app:
1. Go to the **Actions** tab in this repo.
2. Select the latest **"Build Android APK"** workflow.
3. Download the **`veyra-apk`** artifact from the bottom of the page.
